# Core Banking System

A production-ready backend application built with Spring Boot,
Docker support, and Jenkins CI to manage core banking transactions
with secure APIs, auditing, and event processing.

## 🔧 Tech Stack

- **Language:** Java
- **Framework:** Spring Boot
- **CI/CD:** Jenkins
- **Containerization:** Docker
- **Event Streaming:** (if used) Apache Kafka
- **Database:** MySQL / PostgreSQL / H2 (configurable)

## 🚀 Features

- REST APIs for account creation and transaction processing
- Secure authentication and authorization
- Docker container support for easy deployment
- Jenkins pipeline for automated build and deploy
- (Optional) Kafka event streaming

## 🧪 How To Run

1. Clone the repository
2. Configure database and environment variables
3. Build the app:
   ```bash
   mvn clean package
